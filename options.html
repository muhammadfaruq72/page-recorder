Page Viewport
FULLSCREEN · ALIGNED LEFT

Desktop viewport

Click the toolbar button to enter fullscreen with a fixed webpage viewport aligned to the left. Click again to restore the page and exit fullscreen. Both modes change the page surface inside the browser.

Desktop dimensions

Height 0 uses the available fullscreen height. Dimensions are CSS pixels. The whole viewport fits on screen with its aspect ratio preserved, aligned at the upper-left. Window width and height are never set by the extension.

SAME TAB · MOBILE LAYOUT

Mobile viewport

Use a mobile layout inside the same fullscreen browser, aligned left. Your page stays on the original tab with no Inspect window or embedded page.

Mobile dimensions

Default: 390 × 844. Touch emulation is enabled in mobile mode. Both modes use native viewport emulation; Chrome/Arc may show its debugging banner. Close Inspect before activating.

SAVE YOUR POSITIONS

Scroll points

Turn on collection, open your webpage, scroll to a position, and click Save scroll point before activating viewport mode. Positions are saved per page URL in collection order. The button returns after viewport mode turns off if collection is still enabled.

Turn collection off when finished. While viewport mode is on, press the next-point shortcut to move smoothly to each position. A new activation starts at the first point. After the last point, additional presses do nothing. Points use the document’s vertical scroll offset; collection supports HTTP and HTTPS websites.

CONTROL EVERY MOVEMENT

Smooth scrolling

Each shortcut press scrolls down by your saved percentage, a full viewport height, or to the next saved point while viewport mode is on.

Smooth scrolling animation settings

The full-height shortcut always moves down by 100% of the emulated viewport height. Next-point scrolling uses the same transition and duration. Repeated presses queue separate movements.
